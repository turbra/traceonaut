# Choosing a Dashboard

Import a dashboard for each source you collect. Each view has its own UID.

## Codex

Start with **Work Overview**.

| Dashboard | Use it for |
| --- | --- |
| [Work Overview](work-overview.md) | Session and subagent activity, usage, commands and collector health. |
| [All Sessions](all-sessions.md) | A compact session inventory and usage summary. |
| [Codex TUI · Beta](tui-beta.md) | The Codex CLI Usage screen in Grafana. |
| [CWO Overview](cwo.md) | CWO sessions, agents, usage and workflow activity. |

## IBM Bob

| Dashboard | Use it for |
| --- | --- |
| [IBM Bob · Beta](ibm-bob-beta.md) | Chats, saved and captured tokens, responses and tool results. |

See [Reading the Values](reading-values.md) for Codex and
[Read the Values](ibm-bob-beta.md#read-the-values) for Bob.
[Dashboard Reference](../reference/dashboards.md) lists templates and renderers.
