# Quick Start

import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';

Complete [Install](install.md), then run these commands from the checkout root
as the user who owns the source profiles. If replacing a running collector, stop
it first and reuse its private storage and endpoint token.

## 1. Run the Collector

Set your profile paths and create private collector storage:

{/* <!-- setup-paths --> */}
```bash
export TRACEONAUT_CODEX_HOME="$HOME/.codex"
export TRACEONAUT_BOB_HOME="$HOME/.bob"
export TRACEONAUT_DATA_DIR="$HOME/.local/share/traceonaut"
export TRACEONAUT_METRICS_CREDENTIAL="$TRACEONAUT_DATA_DIR/metrics.token"
export TRACEONAUT_LISTEN_ADDRESS="127.0.0.1"
install -d -m 700 "$TRACEONAUT_DATA_DIR"
```

Create the endpoint token once; reuse it on restart:

{/* <!-- credential-create --> */}
```bash
python3 scripts/create_metrics_token.py --credential-file "$TRACEONAUT_METRICS_CREDENTIAL"
```

Choose the network layout:

<Tabs groupId="network">
<TabItem value="local" label="Same Machine" default>

Keep `127.0.0.1` when Prometheus runs directly on this workstation.

</TabItem>
<TabItem value="remote" label="Remote Server">

Use your workstation's numeric LAN/VPN address:

```bash
export TRACEONAUT_LISTEN_ADDRESS="192.0.2.10"
```

Replace the example address with one assigned to your workstation.

</TabItem>
<TabItem value="container" label="Container Prometheus">

Use a workstation LAN/VPN address reachable from the container:

```bash
export TRACEONAUT_LISTEN_ADDRESS="192.0.2.10"
```

Mount the token read-only inside Prometheus at `/etc/prometheus/traceonaut/metrics.token`.
A container's loopback points to itself. Host networking also works when both processes share it.

</TabItem>
</Tabs>

For remote HTTP, use a trusted private LAN, encrypted VPN or HTTPS proxy and
allow only Prometheus through the firewall. See [Network and Security](operations/network-and-security.md).

Choose one source configuration:

## 2. Add the Prometheus Scrape Job

Give Prometheus a protected copy of the endpoint token, readable by its service
user. Set `credentials_file` to its absolute path as seen by Prometheus.
Add this job to your existing configuration:

<Tabs groupId="network">
<TabItem value="local" label="Same Machine" default>

{/* <!-- prometheus-scrape --> */}
```yaml
scrape_configs:
  - job_name: traceonaut
    scrape_interval: 5s
    scrape_timeout: 4s
    authorization:
      type: Bearer
      credentials_file: /absolute/path/to/traceonaut/metrics.token
    static_configs:
      - targets: ['127.0.0.1:9464']
```

</TabItem>
<TabItem value="remote" label="Remote Server">

Copy the token securely to the Prometheus server and use the workstation address chosen in step 1.

{/* <!-- prometheus-scrape-remote --> */}
```yaml
scrape_configs:
  - job_name: traceonaut
    scrape_interval: 5s
    scrape_timeout: 4s
    authorization:
      type: Bearer
      credentials_file: /etc/prometheus/traceonaut/metrics.token
    static_configs:
      - targets: ['192.0.2.10:9464']
```

</TabItem>
<TabItem value="container" label="Container Prometheus">

Use the mounted token path and the workstation address chosen in step 1.

{/* <!-- prometheus-scrape-container --> */}
```yaml
scrape_configs:
  - job_name: traceonaut
    scrape_interval: 5s
    scrape_timeout: 4s
    authorization:
      type: Bearer
      credentials_file: /etc/prometheus/traceonaut/metrics.token
    static_configs:
      - targets: ['192.0.2.10:9464']
```

</TabItem>
</Tabs>

Validate and reload Prometheus:

```bash
promtool check config /path/to/prometheus.yml
```

Check `up{job="traceonaut"}` in Prometheus; expect `1`.

## 3. Import a Dashboard into Grafana

Run the renderer for each source you selected, from the checkout root in a second terminal.

**Codex**

{/* <!-- render-beta --> */}
```bash
export TRACEONAUT_DATA_DIR="$HOME/.local/share/traceonaut"
python3 scripts/render_codex_beta_dashboard.py \
  --template examples/observability/codex-work-overview-beta.json \
  --snapshot-file "$TRACEONAUT_DATA_DIR/sessions.json" \
  --output "$TRACEONAUT_DATA_DIR/work-overview.json"
```

**IBM Bob**

{/* <!-- render-bob --> */}
```bash
export TRACEONAUT_DATA_DIR="$HOME/.local/share/traceonaut"
python3 scripts/render_bob_dashboard.py \
  --template examples/observability/ibm-bob-beta.json \
  --snapshot-file "$TRACEONAUT_DATA_DIR/bob.json" \
  --output "$TRACEONAUT_DATA_DIR/ibm-bob-beta.json"
```

In Grafana, open **Dashboards → New → Import**, upload the rendered file, and
select your Prometheus datasource. Use `work-overview.json` for Codex and
`ibm-bob-beta.json` for IBM Bob. When collecting both, import both dashboards.

See [Automatic Name Updates](operations/automatic-name-updates.md) to refresh Project and Chat names as you work.
