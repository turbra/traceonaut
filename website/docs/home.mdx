## Documentation

New to Traceonaut? [Install the collector](/install/), then follow the
[Quick Start guide](/getting-started/) to collect metrics and view them in
Grafana. Dashboard guides and operating instructions are below.

## How it works

<ol className="traceonaut-flow" aria-label="Metrics flow">
  <li><strong>Codex files</strong><span>On your workstation</span></li>
  <li><strong>Collector</strong><span>Reads files and serves metrics</span></li>
  <li><strong>Prometheus</strong><span>Scrapes and stores samples</span></li>
  <li><strong>Grafana</strong><span>Queries Prometheus</span></li>
</ol>

Prometheus pulls from the collector's authenticated `/metrics` endpoint. Your
existing Prometheus and Grafana can run on the same machine or a separate server.
OpenTelemetry, node_exporter, and alerting services are not required.

For a remote Prometheus server, use a specific reachable LAN/VPN address and
allow only that server through the workstation firewall. Bearer authentication
does not encrypt HTTP. Read the <Link to="/operations/#network-and-credentials">network requirements</Link>
before exposing the endpoint. A sleeping or disconnected workstation cannot be
scraped, and reconnecting does not backfill missed samples.

## Optional CWO integration

[Complex Work Orchestration (CWO)](https://github.com/gprocunier/complex-work-orchestration)
is a Codex skill for planning complex tasks, coordinating coding agents, and
tracking work across sessions. Traceonaut's <Link to="/integrations/cwo/">optional integration</Link>
adds dispatch metrics for the <Link to="/dashboards/cwo/">separate CWO dashboard</Link>.
**You do not need CWO for ordinary Codex session collection.**
